# Monitor cambiario de Bolivia

Este dashboard facilita el seguimiento diario del tipo de cambio y del mercado cambiario boliviano para el público general, y ofrece a investigadores una base de datos descargable de alta frecuencia para análisis más detallados.

Monitor cambiario de alta frecuencia para seguir la presión sobre el dólar en Bolivia, comparando la cotización del USDT, los tipos de cambio referenciales bancarios publicados por el Banco Central de Bolivia (BCB), las reservas internacionales y el tipo de cambio real.
